# 🍳 Recipe World - Version 2.0

Here — not recipes, but a platform that is being rebuilt in the style of **Vibe Code**, based on a modern and professional architecture. The project is being worked on jointly by **Azizbek** and **Shahriyor** (frontend warriors).

## 🚀 Project Goal
Using the experience of the first version, the bugs are reduced to 0, multilingual (UZ, RU, EN) and scalable launch.

## 🏗 Technology stack
* **Frontend:** React.js (Vite)
* **Routing:** React Router DOM
* **Icons:** Lucide React
* **State management:** Context API and custom hooks

## 📁 File Structure (Clean Architecture)
The project is at risk due to "Separation of Concerns" (due to tasks):
- `src/components/common` - Reusable UI components (Button, Input).
- `src/context` - Only Providers (Global State).
- `src/hooks` - Only logic and functions (Custom Hooks).
- `src/pages` - As a logical block for each page.
- `src/api` - Data processing part.
